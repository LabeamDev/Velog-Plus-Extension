# Velog Plus

velog.io에서 글을 더 편하게 읽고 작성할 수 있도록 돕는 Chrome 확장입니다.

본문 폭 조절, 글자색·배경색, 서식 단축키, 이미지 편집, 마크다운 불러오기를 지원합니다. 그림이 포함된 자세한 설명은 확장 팝업의 **사용법 보기** 또는 [사용법 페이지](help/help.html)에서 확인할 수 있습니다.

## 본문 폭 조절

글 본문 양옆의 가장자리를 드래그해 폭을 조절합니다. 더블클릭하면 **기본 폭 768px**로 돌아갑니다.

- 확장 팝업에서 폭 조절을 켜거나 끄고, 슬라이더·숫자 입력·프리셋으로 폭을 정할 수 있습니다.
- **480~2400px** 범위의 숫자는 입력 즉시 적용·저장됩니다.
- 블로그 홈의 글·시리즈·소개 탭에도 같은 폭을 적용합니다.
- 태그 목록이 화면 밖으로 나가면 글 목록 안쪽으로 옮깁니다.

## 글자색·배경색

글쓰기 화면에서 글자를 선택한 뒤 툴바의 **글자색(A)** 또는 **배경색(형광펜)** 버튼을 누릅니다. 색상은 원문의 HTML span 요소에 저장되며, 글자색과 배경색별로 최근 사용한 색을 표시합니다.

- **RGB 확인**: 팔레트나 최근 사용 색상에 마우스를 올리면 (R, G, B) 값을 표시합니다.
- **RGB 복사**: 색상을 우클릭하면 본문을 변경하지 않고 RGB 값을 복사합니다. 실패하면 안내에 표시된 값을 선택해 직접 복사할 수 있습니다.
- **원하는 색 입력**: 직접 선택의 색상 선택창을 사용합니다.

RGB 복사에는 불투명도가 포함되지 않습니다. 직접 선택으로 정한 배경색은 불투명하므로, 반투명 배경색을 그대로 재사용하려면 팔레트나 최근 사용에서 고릅니다.

## 서식·강조 단축키

글쓰기 본문에서 글자를 선택한 뒤 사용합니다.

| 기능 | macOS | Windows |
| --- | --- | --- |
| 굵게 | Command+B | Ctrl+B |
| 기울임 | Command+I | Ctrl+I |
| 밑줄 | Command+U | Ctrl+U |
| 지정한 스타일로 강조 | Command+E | Ctrl+E |
| 실행 취소 | Command+Z | Ctrl+Z |

굵게·기울임은 기존 velog 툴바 버튼과 같은 동작입니다. 밑줄은 선택한 글자가 있을 때만 적용하며, 기존 글자색·배경색을 보존합니다. 같은 선택에서 서식 단축키를 다시 누르면 해제됩니다.

### 강조 스타일 설정

확장 팝업에서 글자색·배경색·굵게·기울임·밑줄을 조합하고 배경 불투명도를 정합니다. 적어도 한 항목은 켜 두어야 하며, 색상 없이 서식만 사용할 수도 있습니다.

강조 단축키를 누르면 다음 규칙으로 선택 영역을 바꿉니다.

- **현재 설정과 모두 같으면 전체 해제**합니다.
- 적용된 항목이 없거나 일부만 일치하면 **현재 설정으로 맞춥니다**.
- **체크한 색·서식만 남깁니다.** 체크 해제한 항목은 기존에 적용돼 있어도 선택 영역에서 지웁니다.

여러 줄 선택을 지원하며, 선택 밖의 서식은 보존합니다. 선택한 글자가 없으면 변경하지 않습니다. 이미 강조한 글자도 다시 선택해 스타일을 바꿀 수 있습니다.

설정은 자동 저장되며 단축키를 누를 때 최신 값을 다시 읽습니다. 설정 연결이 끊기면 새로고침을 안내합니다. 강조 설정은 본문 폭 조절의 켜기·끄기와 독립적으로 사용할 수 있습니다.

## 이미지 편집

글쓰기 미리보기의 이미지에 마우스를 올리면 이미지 도구가 나타납니다.

### 크기 조절·자르기

- **크기 조절**: 25%·50%·75%·100%·원본 버튼 또는 오른쪽 드래그 핸들을 사용합니다. 크기는 본문 폭 대비 비율이며, 원문의 HTML 이미지 width 속성에 저장됩니다.
- **자르기**: 잘라낸 이미지를 velog에 다시 업로드하고 원문 주소를 바꿉니다. 임시저장된 글에서 사용할 수 있습니다.

### 이미지 합치기

1. 이미지 도구에서 **합치기**를 누릅니다.
2. 미리보기에서 합칠 이미지 여러 장을 선택합니다.
3. 배치·맞춤·간격·배경을 정합니다.
4. 한 장으로 합쳐 업로드하면 원문의 첫 이미지 자리에 넣습니다.

가로 한 줄·세로 한 줄·격자 배치를 지원합니다. 행·열 수를 조절하고, 칸을 클릭해 이미지를 교환하거나 빈 칸으로 옮길 수 있습니다. 맞춤 방식은 원본 비율·채우기·맞추기 중에서 고릅니다.

velog에서 이미지를 나란히 배치하기 위해 여러 장을 한 장으로 합치는 방식입니다.

## 마크다운 불러오기

1. 글쓰기 툴바의 **불러오기** 버튼을 누릅니다.
2. **.md 파일과 이미지 파일**, **폴더**, 또는 **zip 파일**을 선택합니다.
3. 제목·태그·본문을 채우고, 로컬 이미지는 velog에 업로드해 주소를 바꿉니다.

제목은 머리말의 title 값 또는 첫 줄의 1단계 제목에서, 태그는 머리말의 tags 값에서 가져옵니다. 글 번호가 없으면 먼저 임시저장합니다. **출간은 사용자가 직접 합니다.**

## 설치

1. Chrome 주소창에 **chrome://extensions**를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 폴더를 선택합니다.
4. 퍼즐 아이콘에서 **Velog Plus**를 고정합니다.

확장 파일을 수정한 뒤에는 확장 관리 화면의 새로고침 버튼을 누르고, velog 탭도 새로고침합니다.

## 테스트

Node.js가 설치된 환경에서 프로젝트 폴더의 터미널로 실행합니다.

```bash
node --test test/*.test.js
```
