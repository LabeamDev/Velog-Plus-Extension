# Velog Plus

velog.io 전용 크롬 확장. 기능별 사용법(그림 포함)은 확장 팝업의 사용법 보기, 또는 help/help.html.

- 글 페이지: 본문 양옆 가장자리를 드래그해 본문 폭 조절 (더블클릭 시 원래 768px). 블로그 홈(글·시리즈·소개 탭)도 같은 폭을 쓰고, 태그 목록이 화면 밖으로 나가면 글 목록 안쪽으로 옮긴다.
- 확장 아이콘 팝업: 폭 켜기/끄기, 슬라이더, 숫자 입력, 프리셋. 480~2400px 숫자는 입력 즉시 적용·저장된다.
- 글쓰기 화면: 툴바에 글자색(A)·배경색(형광펜) 버튼. 선택 글자를 `<span style="...">`로 감싸며, 글자색·배경색 각각 최근 사용한 색을 표시한다.
- RGB 표시·복사: 팔레트와 최근 사용 색상에 마우스를 올리면 **(R, G, B)** 표시, **우클릭**하면 본문 변경 없이 RGB 값을 복사한다. 원하는 색은 **직접 선택**의 색상 선택창에서 입력한다. RGB 복사에는 불투명도가 포함되지 않으며, 직접 선택으로 정한 배경색은 불투명하다. 반투명 배경색을 그대로 재사용하려면 팔레트나 최근 사용에서 고른다. 복사 실패 시 안내에 표시된 RGB 값을 선택해 직접 복사한다.
- 서식 단축키: 본문 글자를 선택하고 macOS **Command+B / Command+I / Command+U**, Windows **Ctrl+B / Ctrl+I / Ctrl+U**로 각각 굵게·기울임·밑줄을 적용한다. 같은 선택에서 다시 누르면 해제된다. 굵게·기울임은 기존 velog 툴바 버튼과 같은 동작이며, 밑줄은 선택한 글자가 있을 때만 적용되고 기존 글자색·배경색을 보존한다. 실행 취소는 macOS Command+Z / Windows Ctrl+Z.
- 강조 단축키: 팝업에서 글자색·배경색·굵게·기울임·밑줄을 조합하고 배경 불투명도를 설정한다. 색상 없이 서식만 사용할 수도 있으며 적어도 한 항목은 켜 둔다. 본문 글자를 선택하고 macOS **Command+E / Windows Ctrl+E**로 실행한다. 선택 전체가 현재 설정과 같으면 한 번에 해제하고, 다르면 현재 설정으로 맞춘다. **굵게·기울임·밑줄은 체크한 항목만 남기며, 체크 해제한 서식은 기존에 적용돼 있어도 선택 영역에서 지운다.** 선택 밖 서식과 꺼 둔 글자색·배경색은 보존한다. 여러 줄 선택도 지원한다. 선택이 없으면 변경하지 않는다. 설정은 자동 저장되며 단축키를 누를 때 최신 값을 다시 읽는다. 설정 연결이 끊기면 이전 값으로 실행하지 않고 새로고침을 안내한다. 이미 강조한 글자는 다시 선택하고 단축키를 눌러 바꾼다. 본문 폭 켜기/끄기와 독립적이다.
- 글쓰기 미리보기 이미지: 마우스를 올리면 크기 버튼(25/50/75/100%/원본)·오른쪽 드래그 핸들·자르기 버튼. 크기는 본문 폭 대비 % 로 `<img width="N%">` 에 저장. 자르기는 잘라낸 이미지를 velog 에 다시 올리고 원문 주소를 바꾼다(임시저장된 글만).
- 이미지 합치기: 이미지 도구의 합치기 → 미리보기에서 이미지 여러 장 클릭 → 배치(가로 한 줄·세로 한 줄·격자, 행·열 조절, 칸 클릭으로 자리 바꾸기·빈 칸), 맞춤(원본 비율·채우기·맞추기), 간격·배경 선택 → 한 장으로 합쳐 올리고 원문의 첫 이미지 자리에 넣는다. velog 는 이미지를 나란히 둘 수 없어 합치는 방식을 쓴다.
- 마크다운 불러오기: 글쓰기 툴바의 불러오기 버튼 → .md + 이미지 파일, 폴더, 또는 zip 선택 → 제목(머리말 title 또는 첫 줄 # 제목)·태그(머리말 tags)·본문을 채우고, 로컬 이미지는 velog 에 올려 주소를 바꾼다. 글 번호가 없으면 먼저 임시저장한다. 출간은 사용자가 직접 한다.

## 설치

1. chrome://extensions 열기
2. 오른쪽 위 개발자 모드 켜기
3. 압축해제된 확장 프로그램을 로드합니다 → 이 폴더 선택
4. 퍼즐 아이콘에서 Velog Plus 고정

코드 수정 후에는 chrome://extensions 에서 새로고침 버튼을 누르고 velog 탭도 새로고침한다.
